GARD 공개 전시장 + 구독자 앱 v3.0
공개용 ZIP만 GitHub에 업로드합니다. 비공개 ZIP, owner.html, private, 원장/백업, 암호화 전달 파일, 질문 파일은 업로드 금지.
1. GitHub에서 새 저장소 생성 → GitHub Desktop File > Clone repository → Repository > Show in Explorer.
2. 이 ZIP의 내용 전체 복사 → Commit → Push → Netlify에서 저장소 연결. 빌드 명령 없음, publish directory .
3. 배포 주소의 /index.html 전시장, /subscriber.html 구독자 앱. 초기 공개 0건.
4. 오너가 승인 및 미리보기한 public.json만 data/public.json 교체 후 Commit/Push. 공개 이력은 Git에 남을 수 있습니다.
5. 구독자에게 암호화 JSON을 이메일 등으로, 암호는 다른 채널로 전달. HTTPS 구독자 앱에서 파일 선택/암호 입력/복호화/질문 JSON 저장. 질문은 별도 채널로 오너에게 전달.
6. 로그인 인증, 원격 접근 철회, 결제 기능 없음. 구독자 앱은 공개 코드이며 전달 파일의 암호로 열람합니다. 제공된 자료 복제 방지는 불가능합니다.
7. 민감 자료는 신뢰할 수 있는 배포 코드에서만 열람하세요.
